# Contribuindo

Contribuições são bem-vindas, principalmente:

- Nomes de menu diferentes em outros idiomas/regiões (informe idioma e data em que viu).
- Novos papéis com o conjunto mínimo de permissões (ex.: moderador, analista).
- Mudanças na interface da Meta que deixaram algum passo desatualizado.

## Como enviar

1. Faça um fork e crie um branch.
2. Edite `skills/meta-business-team-access/SKILL.md`, mantendo o frontmatter (`name`, `description`) válido.
3. Descreva no pull request o que mudou e como você confirmou (sem prints com IDs, nomes ou dados pessoais).

## Regras

- Nunca inclua IDs reais de Business Portfolio, Páginas, contas ou dados de pessoas.
- Não sugira passos que envolvam digitar a senha de outra pessoa.
